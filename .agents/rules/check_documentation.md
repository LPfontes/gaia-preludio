## 1. Verificação de Documentação
- **Foundry VTT v14**: Consultar [`docs/FOUNDRY_V14_API.md`](file:///c:/Users/lpfon/AppData/Local/FoundryVTT/Data/systems/gaia-preludio/docs/FOUNDRY_V14_API.md) antes de criar ou modificar códigos envolvendo APIs do Foundry.
- **Regras do Sistema**: Consultar [`DOCUMENTACAO_SISTEMA.md`](file:///c:/Users/lpfon/AppData/Local/FoundryVTT/Data/systems/gaia-preludio/DOCUMENTACAO_SISTEMA.md) para garantir conformidade nas fórmulas, rolagens, condições e fluxo de combate.

## 2. Padrões Visuais & CSS
- **Proibição de Emojis**: Não inserir emojis em textos, botões, diálogos, títulos ou mensagens de chat. Utilizar ícones FontAwesome (`fa-solid fa-...`) quando necessário.
- **Variáveis CSS como Padrão**: Utilizar sempre os design tokens definidos em [`styles/base/variables.css`](file:///c:/Users/lpfon/AppData/Local/FoundryVTT/Data/systems/gaia-preludio/styles/base/variables.css) (`var(--gaia-*)`) para cores, fundos, bordas e tipografia, evitando cores fixas/hardcoded.
